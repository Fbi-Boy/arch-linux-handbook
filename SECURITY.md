# Security Policy

This is documentation, but incorrect commands can cause data loss or weaken system security.

## Reporting
Report commands that expose credentials, weaken access controls, unexpectedly destroy data, or create unsafe configurations through a private GitHub security report where available. Do not publish secrets or personal data in issues.

## Rules
- Never request passwords, private keys, tokens, or recovery keys.
- Do not disable security controls without documenting consequences.
- Mark destructive storage operations clearly.
- Prefer least privilege.
- Keep security-sensitive procedures tied to authoritative references.
