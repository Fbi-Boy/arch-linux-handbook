# 01 — Preparation

## Checklist
- [ ] Back up important files.
- [ ] Confirm target disk and available space.
- [ ] Record the existing partition map if dual booting.
- [ ] Confirm UEFI or legacy firmware mode.
- [ ] Review Secure Boot requirements.
- [ ] Prepare a reliable USB drive.
- [ ] Ensure stable internet access.
- [ ] Keep another device available for recovery research.

## Dual boot
Do not resize or delete Windows partitions until the backup and partition map are verified. Record the EFI System Partition and recovery partitions.

## Gate
Do not begin installation until you can identify the physical target disk, partitions that must remain untouched, and the recovery route if boot configuration fails.
