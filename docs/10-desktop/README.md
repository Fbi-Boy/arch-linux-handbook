# 10 — Desktop Environment

Arch provides a minimal base and does not force a graphical desktop. The desktop is a separate design layer.

## Paths
- KDE Plasma
- GNOME
- XFCE
- Minimal window manager/compositor

## Each desktop page must cover
- packages
- display manager
- graphics stack
- network integration
- audio
- portals where relevant
- fonts
- screenshots
- performance notes
- removal or rollback

Do not rank desktops as universally better. Selection depends on hardware, workflow, graphics protocol requirements, application compatibility, and preference.
