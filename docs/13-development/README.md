# 13 — Development Environment

This layer creates a reproducible developer workstation after the operating system is stable.

## Toolchain
- Git and SSH
- GitHub
- PHP and Composer
- Node.js and npm
- Python
- VS Code
- Docker
- MariaDB/MySQL
- Laravel
- Flutter

## Standard
Install → configure → version check → minimal test → common errors → rollback.

Development tools should not be used as a substitute for fixing a broken base system.
