# 11 — Hardware

Hardware support is device-specific. Detect hardware before selecting drivers or configuration.

## Categories
- CPU and microcode
- GPU
- Wi-Fi
- Bluetooth
- Audio
- Touchpad
- Keyboard
- Brightness
- External displays
- Webcam
- Power management
- Suspend and hibernate

## Target laptop profile
A dedicated Lenovo V14 G2 ALC / Ryzen 3 5300U profile may be added, but every hardware claim must be verified from actual device information.

## Diagnostic pattern
Detect → identify driver/firmware → configure → verify → persist → reboot test.
