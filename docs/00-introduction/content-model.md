# Content Model

Each procedure follows this template:

## Title

### Goal
What the operation accomplishes.

### Prerequisites
What must already be true.

### Safety
What can go wrong and what must not be touched.

### Procedure
Numbered, copyable actions.

### Expected result
Observable output or system state.

### Verification
A command or test proving success.

### Troubleshooting
Known failures and their first diagnostic step.

### Recovery
How to return to a safe state.

### References
Specific authoritative upstream sources.

### Next step
The exact next document in the workflow.
