# 00 — Introduction

Arch Linux is an x86-64 general-purpose distribution following a rolling-release model and a minimal-by-default installation approach. The official installation guide is intentionally concise and points to detailed ArchWiki articles.

This handbook adds a structured execution and learning layer without replacing ArchWiki.

## Baseline
- x86-64 hardware
- UEFI firmware
- official Arch installation image
- working internet connection
- verified backup before storage changes

## How to use
Follow numbered sections in order. If a checkpoint fails, stop and use the relevant troubleshooting path instead of improvising.

## Scope
Generic installation, configuration, desktop setup, hardware, security, development, dual boot, maintenance, troubleshooting, and recovery.
