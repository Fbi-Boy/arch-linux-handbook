# Research and References

## Primary authority

### ArchWiki
https://wiki.archlinux.org/

The ArchWiki is the primary technical reference for this project.

### Installation Guide
https://wiki.archlinux.org/title/Installation_guide

Use it as the canonical baseline for the installation sequence.

### General Recommendations
https://wiki.archlinux.org/title/General_recommendations

Use it as the baseline for system administration, package management, security, maintenance, desktop, and post-installation topics.

## Documentation platform reference

### Docusaurus
https://docusaurus.io/

Docusaurus is the planned documentation-site platform because it supports hierarchical Markdown documentation, sidebars, search, customization, and optional versioning.

## Reference policy

Every page should cite the specific upstream article relevant to the procedure rather than linking only to a generic homepage.
