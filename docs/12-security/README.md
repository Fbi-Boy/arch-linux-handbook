# 12 — Security

## Baseline
- Use an unprivileged daily account.
- Keep packages updated through supported workflows.
- Read current Arch news before upgrades when manual intervention may be required.
- Minimize exposed services.
- Protect SSH credentials and private keys.
- Consider disk encryption when the threat model requires it.
- Maintain tested backups.

## Threat-model rule
State what a control protects against. Encryption at rest, firewalling, account separation, and backups solve different problems.
